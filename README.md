# 二年级上册 · 语文园地四 · 我的发现 —— 颜色歌

小学语文二年级上册，语文园地四“我的发现”板块配套学习资料。

## 内容
《颜色歌》围绕四种基础颜色及其深浅变化展开：
- 白：雪白、米白、奶白
- 红：火红、桃红、枣红
- 黄：土黄、鹅黄、金黄
- 绿：草绿、翠绿、墨绿

### 歌词
白色雪白好清新，米白奶白亮晶晶。
红色火红照人明，桃红枣红笑盈盈。
黄色土黄亮晶晶，鹅黄金黄放光明。
绿色草绿满园青，翠绿墨绿护森林。

### 生字（16 个）
白色、雪白、米白、奶白、红色、火红、桃红、枣红、
黄色、土黄、鹅黄、金黄、绿色、草绿、翠绿、墨绿。
