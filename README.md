# 颜色歌 · REARMED

二年级上册 · 语文园地四 · 我的发现 —— 互动学习项目（REARMED 离线课堂模板）。

## 内容
- 《颜色歌》儿歌：白色 / 红色 / 黄色 / 绿色 四组，每组含深浅变化
  - 白：雪白、米白、奶白
  - 红：火红、桃红、枣红
  - 黄：土黄、鹅黄、金黄
  - 绿：草绿、翠绿、墨绿
- 9 张配套色彩插图（含封面）
- 歌曲音频（mp3）
- 16 个生字卡片，点击可听发音（浏览器语音合成，需设备支持中文嗓音）

## 运行方式
纯本地离线网页，**无需服务器、无需联网**：
- 直接用浏览器打开 `index.html` 即可；
- 或部署到 GitHub Pages / 任意静态空间，手机扫码即可学习。

## 目录结构
- `index.html` —— 主页面（歌曲播放、歌词插图、生字互动）
- `assets/` —— 插图与音频（已重命名为 ASCII 文件名，避免中文特殊字符问题）

## REARMED
本项目的离线互动课堂模板，适用于小学语文“我的发现”系列，可沿用此结构为各单元快速生成同类学习页。
